## Instalación

Clona el repositorio:

```bash
git clone https://github.com/ChrisARP12/Portafolio.git
```

Instala las dependencias:

```bash
npm install
```

Inicia el servidor de desarrollo:

```bash
npm run dev
```

---

## Build de producción

```bash
npm run build
```
